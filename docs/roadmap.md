# Roadmap

This repository starts with a narrow, testable listing assistant. The items below are plans, not current features.

## Hacktoberfest Week 2 candidate

- Verify the local open-weight model flow end to end.
- Interview one potential lender about the suggested prices and listing quality.
- Publish an English DEV article explaining the user, the demo, and why local open AI matters.
- Record a short demo and link the exact commit used for the challenge.

## Amazon Developer Hackathon candidate

- Add a simulated Alexa+ experience for multi-step listing creation.
- Add state across sessions, availability checks, and user approval before a listing is saved.
- Consider a Streamable HTTP MCP server only if there is time to implement and test it fully.
- Prepare a public video shorter than three minutes and required product feedback.

## Marketplace direction

- Conflict-safe bookings and availability calendars.
- Handover and return condition evidence.
- Privacy-aware neighbourhood search.
- Real payments only after appropriate provider, legal, and safety work.
